# Reportes API

Cada pipeline genera aquí `index.html` y `resumen.json`, asociados a su commit y run. El artefacto final incluye los reportes HTML completos en `reports/raw/`, con enlaces desde el consolidado. El historial no se reemplaza por un reporte de otra revisión. Última evidencia previa a la reorganización: [run aprobado 44662207228](https://github.com/granitespinoza/qolqe-g4-qa/actions/runs/44662207228). Los resultados finales de la reorganización se consultan en Actions por el commit entregado.
